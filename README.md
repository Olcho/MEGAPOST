# YOU ARE REPLACEABLE — MEGAPOST v8.1.2 (보관함 및 EVE 종료 대화 핫픽스)

2080년 서울 물류기업의 관제 담당자가 반복 근무를 거치며 사고 기록을 조사하는 사이버펑크 로그라이트 게임입니다.

## v8.1.2 핫픽스

- 감사 문서 발견 후 `help`에 `archive`를 표시하고 `help archive`를 제공. 발견한 문서는 교대 이후에도 색인에서 유지. ID와 접근 코드는 자동 공개하지 않습니다.
- 9개 결말별 EVE 종료 대화와 전용 질문을 추가하고, 종료 후 자유 입력도 업무 진행 안내 대신 결과를 회고하도록 분리했습니다.
- v8.1.1의 포커스 수정 및 신규 대응 강조를 포함하며 기존 저장 키와 게임 분기를 유지합니다.

## v8.1.1 핫픽스

- `help status`의 실제 사용법을 추가하고, `help help`, `help cls`에 기능 설명 및 EVE의 숨은 반응을 추가했습니다.
- 명령 저장 중에도 입력창을 비활성화하지 않으며, 실행 후 포커스를 유지합니다. 저장이 실패하면 기존 입력을 복원합니다.
- R-771 사진 조사에서 `photo` 권한 이름을 사전에 확인할 수 있도록 안내합니다. `image`, `사진`, `사진 원본`도 같은 권한으로 인식합니다.
- R-771 보관 기록은 촬영 건물/주문 주소, 문서 ID, 추가 조사 목적, 접근 코드 규칙으로 분리했습니다. 완성된 열람 명령이나 코드는 노출하지 않습니다.
- 터미널 해금 대응은 별도 영역과 테두리, 신규 대응 표식 및 짧은 등장 효과로 구분합니다. 근무 종료 분석은 결정적 원인을 유지하고 미래 회차의 직접적인 공략 안내는 제거합니다.
- 사건 수, 선택지 조건, 엔딩, 기존 저장 키와 명령열 형식은 유지했습니다.

## v8.1 마이너 변경

- **조사 목표와 진행 단계 분리:** 현재 업무와 터미널 조사를 상단에 고정하고, 필요한 정보만 단계별로 표시합니다. 완성된 명령어나 자동입력은 제공하지 않습니다.
- **명령 입력 개선:** `D204`, `D-204` 등의 식별자 표기를 허용하고, 누락된 대상이나 권한을 알기 쉽게 안내합니다. ↑ ↓ 키로 이번 근무의 이전 명령을 다시 불러올 수 있습니다.
- **조사 후 즉시 피드백:** 비행기록을 확보하면 터미널에 결과 카드가 나타나고, 배송관제 지도에는 우회 후보가 파란 점선으로 표시되며 새로운 선택지가 열립니다.
- 스토리, 기존 엔딩 K4/K5, 사건과 해금 조건, v8 저장 키는 유지됩니다.
- 상세 변경 사항: `docs/V8_1_TERMINAL_UX.md`

## v8 기본 기능

- 사이드바에서 **업무(배송 관제, 터미널)**와 **기록(기록 보관함, 결과 도감)**을 각각 묶고, **설정**은 하단에서 별도로 엽니다. 데스크톱 사이드바 높이는 본문 길이에 영향받지 않습니다.
- 터미널은 사건과 관련된 **조사 방향만** 표시합니다. 클릭해도 완성된 명령을 자동으로 입력하지 않습니다. `help`는 기본 문법을 보여주며, 이야기에서 아직 등장하지 않은 ID는 노출하지 않습니다.
- `auth`는 현재까지 알게 된 범위만 보여주므로 사용자는 관련 기록에서 확인한 장비 ID, 접근 범위, 명령을 직접 조합합니다. 기본 문법을 모를 때는 `help <기능>`을 사용할 수 있습니다.
- EVE의 상황별 의견, 업무 농담, 동료와 기사에 관한 대사를 추가했습니다. 불필요한 배송망 설명 문장은 제거했습니다.
- 기존과 같이 회차 종료 후 터미널 출력은 지우되, 영구 기억과 확보한 증거는 보존합니다.
- 비공개 감사 기록, EVE 사건 대화, 기존 업무 선택, K4 진엔딩과 K5 히든엔딩 조건은 유지됩니다.

## 실행

```sh
npm ci
npm run dev
```

PowerShell에서 npm 스크립트 실행 정책 오류가 나면 `npm.cmd ci`, `npm.cmd run dev`를 사용하세요.

타입 검사: `npx tsc --noEmit`  /  분기 검산: `npm test`  /  빌드: `npm run build`.

브라우저 QA는 개발 서버 실행 후 `node tests/browser.mjs`로 수행합니다. 별도 Chrome/Chromium이 필요한 환경은 `HF_BROWSER`로 실행 파일을 지정하세요.

## 소스

- `src/content.json`: 사건, 선택지, 조건, 엔딩
- `src/engine.ts`: 게임 로직과 명령 재생, 기록 보존
- `src/eve.ts`, `src/EVEPanel.tsx`: EVE의 대사 및 대화 UI
- `src/terminal.ts`, `src/TerminalScreen.tsx`: 명령어, 접근 권한, 비공개 기록, 터미널 UI
- `src/debrief.ts`: 종료 분석
- `src/DispatchDesk.tsx`, `src/DispatchMap.tsx`: 배송 선택 및 지도
- `src/save.ts`: 저장/불러오기

**저장 호환성:** v8은 기존 v6와 동일한 저장 키 `megapost.dispatch.v4` 및 명령열 형식(version 4)을 사용합니다. v6의 진행 기록을 이어갈 수 있지만, 파일 교체 전 설정에서 저장 데이터를 내보내 백업하는 것이 안전합니다.

이번 개편은 `docs/V7_NAV_TERMINAL_EVE.md`, 이전 설계는 `docs/V6_UX_REWORK.md`를 참고하세요.

## V8 조사 목표와 미스터리

사건별 조사 목표는 자연어로 안내하지만, 터미널 명령어는 플레이어가 직접 조합합니다. 반복 장애 기록을 확보한 이후 지도에는 실제 물류 경로와 구분되는 미확인 잔류 신호 연출이 표시됩니다. 세부 사항은 `docs/V8_TERMINAL_MYSTERY.md`를 참고하세요.
