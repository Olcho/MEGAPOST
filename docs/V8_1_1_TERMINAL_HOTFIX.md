# v8.1.1 — 터미널 핫픽스

2026-11-24. 기존 v8.1 기반 마이너 수정. 스토리, 16개 사건, 45개 행동, 9개 결말 및 세이브 v4 형식은 유지합니다.

## 사용자 피드백과 적용 사항

- `help status`: 상세 사용법 제공. `help help`, `help cls`(`help clear` 포함): 기능 설명과 EVE의 빈정거리는 숨은 대사. 기본 목록에는 후반 식별자 및 비밀 코드를 노출하지 않음.
- 입력 포커스: 처리 중 입력 필드를 disabled 상태로 만들던 동작 제거. 입력 직후 현재 값을 비우며, 연속 Enter/마우스 제출 시 포커스를 유지. 비동기 저장 중 다음 입력을 보존하고 중복 제출 방지. 저장 실패 시 비어 있는 입력에 이전 명령 복원.
- 사진 조사: 사건별 조사 목표, `auth`, R-771 검색 결과, EVE 답변에서 photo 권한의 의미를 명시. 전체 명령 자동입력은 없음. image, photos, images, 사진, 사진 원본, 이미지, 이미지 원본을 기존 photo 권한의 별칭으로 처리. E05 외 발급 제한 유지.
- R-771 보관 기록: 최초 촬영 위치와 주문서 주소, 보관함/문서 ID, 추가 조사 목적과 접근 코드의 구성 규칙을 구분. 완성 명령과 실제 접근 코드 미공개. 기존 비밀 문서의 해금 조건 유지.
- 해금 보상: 터미널 조건으로 열리는 대응을 일반/기억 기반 선택지와 별도 영역으로 분리, 신규 대응 표시와 짧은 등장 효과. 시스템의 모션 감소 설정 존중.
- 미래 회차 직접 공략: D-204 첫 사고 수신 문구 및 종료 분석의 다음 회차 지시 제거. 현재 회차의 실제 조사 안내와 종료의 결정적 원인은 유지.
