# 5회차 대표 진엔딩 루트 (스포일러)

1. **F1:** 북쪽 경로 자동 승인, EVE 봉인, AI 배차, 오배송 확인 후 실적 제출. AI가 관제석을 대체한다. 장애 시각 M1과 EVE 봉인 W를 보존한다.
2. **F3:** 이전 기록을 이용해 강변으로 우회하고 현장 봉인 C-918을 찾는다. 회사의 중복 지시를 그대로 실행해 권한이 정지된다. M2, M3을 얻는다.
3. **K3:** 이날의 비행 좌표와 현장 스캔으로 테스트 지시를 분리한다. EVE의 증언과 함께 시 안전센터에 접수한다. 관제기 MP-S17 기록 M4를 얻는다.
4. **F4:** 테스트 관제를 바로 끊었다가 실물 냉장차도 멈춘다. 다음 교대 전 예비 회선 예약 방법 M5를 얻는다.
5. **K5:** 07:58 외부 회선을 예약하고 같은 날 실물 스캔과 비행 원본을 모은다. 차량을 외부 안전망으로 옮긴 후 테스트 관제를 중지한다. H07의 기체 정체 E15를 확인하고 E16에서 외부 감사 제출을 선택한다. 기체 기록 M6이 남는다.

검산상 K4와 K5는 각각 최소 4회차에 도달할 수 있다. 시간이나 회차 자체로 선택지를 막는 강제 노가다는 없다. 본문은 간결하게 표시되고 이전 근무에서 발견한 선택을 따로 구분한다.

## 상태
- 영구: M1~M6, W, 발견한 엔딩과 로그.
- 당일: P(마감 실적), A(자동 승인), 항로와 예비차, 원본 비행기록(trace), EVE의 당일 증언(witness), 외부 회선 예약(hold).
- 회사 기준: AI 자동 승인만 늘리면 F1, 처리 실적이 적으면 F2, 균형 있게 대응하면 K1. 회사의 인간 수준 평가 K4와 자율 기록 제출 K5는 후반 사건에 따라 갈린다.
