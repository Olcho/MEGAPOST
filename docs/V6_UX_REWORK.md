# v6 조작 흐름 및 관제 UI 개선

## 주요 변경

- EVE 대화: 업무 상황별 빠른 질문, 장비 및 물류망에 대한 맥락 설명, 퇴근과 불안에 관한 잡담, 추가 선택에 대한 다양한 반응을 추가. LLM이나 외부 API를 호출하지 않음.
- 터미널 출력은 **근무 종료 즉시** 초기화하며 다음 출근 시에도 비어 있음. 이력 재생을 위한 명령열, 획득한 기억, 숨겨진 기록은 유지. 이전 근무의 단서는 자료실 기록 보관함과 종료 분석에서 확인 가능.
- 현재 사건에 유효한 조사 명령이 있으면 배송 관제에서 해당 명령으로 이동하고, 터미널에서는 목적과 근거를 보면서 명령을 입력창에 불러올 수 있음. 입력 즉시 실행하지 않으며 플레이어가 실행 버튼을 선택.
- 터미널에는 배송 관제로 돌아가기 버튼 및 명령 완료 후 복귀 버튼 추가. 해당 시점에 조사에 적합한 명령이 없으면 그 사실을 명시.
- 배송망은 관제 화면과 현장 확인 정보를 나누어 표시하고, 후반에 둘의 불일치가 나타나는 이유를 설명.
- 배송 장비는 각 장비의 현재 가용 상태와 본 사건에서의 의미를 함께 표시하며, 현재 사건에 해당하는 장비를 강조.
- 좌측 메뉴는 '업무: 배송 관제, 터미널' / '기록 및 관리: 자료실'로 분리. 자료실 내부에서 기록 보관함, 결과 도감, 설정을 전환함.

## 설계 의도

터미널이 숨겨진 정답을 입력하는 별도 퍼즐이 아니라, 배송 사고를 해결하는 데 쓰이는 업무 도구라는 점을 전달하는 것이 목적입니다. 접근 권한과 비밀 기록은 기존 조건을 유지하며, 사건별 제안은 플레이어가 현재 확보한 정보 및 정상적인 작업 시점만을 근거로 합니다.

## 이식 및 호환성

- v5와 동일한 `megapost.dispatch.v4` 저장 키와 명령 형식 사용. 기존 v5 세이브를 열 수 있으며 회차 종료 후 터미널 출력만 초기화됩니다.
- 관련 변경: `src/terminalGuidance.ts`, `src/TerminalScreen.tsx`, `src/DispatchDesk.tsx`, `src/DispatchMap.tsx`, `src/EVEPanel.tsx`, `src/eve.ts`, `src/engine.ts`, `src/main.tsx`, `src/style.css`.
- 자동 분기 검산: `npm test`, 타입 검사: `npx tsc --noEmit`, 브라우저 테스트: `node tests/browser.mjs`.
- 브라우저 실행과 Vite 빌드는 실행 플랫폼의 Node 패키지 설치 후 재검증 필요.
