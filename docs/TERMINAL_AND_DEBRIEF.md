# MEGAPOST v4 기반 터미널과 근무 종료 분석 (v5 변경 포함)

## 목적

난이도의 핵심인 기억 축적과 반복 구조는 유지하면서, 막혔을 때 **어떤 선택이 결정적이었는지**, **다음 근무에서 무엇을 조사해 볼 수 있는지**를 근무 종료 화면에 표시합니다. 이를 통해 플레이어가 정답을 자동으로 받는 대신 직접 다음 전략을 세우게 합니다.

## 근무 종료 분석

- F1: AI 이관 횟수와 그날의 자동 승인 선택을 정리
- F2: 마감 처리 점수와 부족한 기준을 설명
- F3: C-918 동일 화물의 두 출고 지시를 그대로 집행한 것이 원인임을 표시
- F4: 실물 배송 차량과 테스트 관제가 같은 통신 회선을 사용한 것을 지적
- K1/K2/K3: 부분 성공 후 아직 해결되지 않은 문제를 명시
- K4: 진엔딩의 성공과 미해결 감사 기록에 대한 약한 복선
- K5: 히든엔딩 완료와 기록 보존의 의미를 표시

각 화면에 다음 근무에서 활용할 수 있는 터미널 명령을 1개 보여주되, 전체 경로를 공개하지 않습니다. 실제 실패 원인은 `debrief.ts`에서 현재 상태와 수행했던 행동을 기준으로 생성합니다.

## 터미널

사이드 메뉴에서 **배송 관제 바로 아래**에 위치합니다. 임의 JavaScript, 브라우저 시스템 호출 또는 OS 명령은 실행하지 않는 **게임 전용 명령어 인터프리터**입니다. 실제로 지원되는 명령과 해금 조건을 `src/terminal.ts`에서 관리합니다.

| 명령 | 기능 | 주요 조건 |
|---|---|---|
| `help` | 명령 목록 | 없음 |
| `status` | 근무 상태 | 없음 |
| `cls` / `clear` | 터미널 출력 지우기 | 없음 |
| `staff lookup <이름/사번>` | 인사 DB 조회 요청. 접근 거부 | 없음 |
| `profile <사번>` | 인사 프로필 조회 요청. 접근 거부 | 없음 |
| `auth request photo` | R-771 이미지 원본 열람 권한 | E05 |
| `auth` | 접근 권한 확인 | 없음 |
| `search D-204` | 드론 장애 기록 검색 | M1 필요 |
| `search C-918` | 실물 봉인 기록 검색 | M2 필요 |
| `search MP-S17` | 재현 관제기 기본 검색 | M4 필요 |
| `auth request flight` | 비행기록 읽기 권한 요청 | M1, E02/E10 |
| `logs D-204` | 기록 복구, 새 업무 선택지 E02.t 해금 | flightAuth, E02/E10 |
| `auth request city` | 외부 관제 회선 권한 요청 | M4, M5, E01 |
| `route reserve C-918` | 외부 예비 회선 예약(hold) | cityAuth, E01 |
| `auth request audit` | 기밀 감사 기록 열람 권한 요청 | M4, 당일 EVE 증언(witness), E14 |
| `inspect MP-S17` | 실험체 단서 조사 및 E14.c 해금 | auditAuth, E14 |

v5에서 별도 힌트 배너와 `hint` 명령을 삭제했습니다. **비공개 감사 보관 기록**은 정상 도움말에 명령이 나오지 않습니다. 수신된 보관 경로를 따라 `archive`를 탐색하고 사건에서 수집한 표찰과 시각으로 접근 코드를 유추해야 합니다. 직원 명부는 본인을 포함해 조회할 수 없습니다.

선택지에서 C-918, MP-S17 등의 식별자를 확인하면 자동 시스템 메시지가 터미널에 도착합니다. 명령 입력과 출력, 권한 변화는 `engine.ts`의 상태 전이로 저장되며 `save.ts`에서 다른 행동과 같이 재생됩니다. 새로운 근무에서는 일시 권한이 사라지지만 감사 메시지와 기억 기록은 유지됩니다.

## 엔딩

- K4 **진엔딩 / 마지막 교대**: 실제 배송을 외부 관제망으로 이전하고 MP-S17을 종료해 반복 근무를 멈춤
- K5 **히든엔딩 / 등록되지 않은 사람**: EVE의 원본 증언과 터미널 감사 원본을 확보해 E14.c가 해금된 뒤 기체 정체를 확인하고 외부 감사 기록을 제출
- K5를 보지 않고도 K4에서 스토리가 완결되어야 하며, E14의 기밀 기록은 일반 경로에서 자동 공개되지 않음

## 저장 호환성

v4는 `megapost.dispatch.v4` 키를 사용합니다. 과거 v3(`megapost.dispatch.v3`), v2, HUMAN FIRST v1 기록은 덮어쓰지 않습니다. 엔딩 전이 구조가 바뀌어 v3 명령열을 v4에서 그대로 복원하지 않으며, 이전 버전 저장이 있다면 설정에서 별도 내보내기를 제공합니다.

## 실행 및 검증

```sh
npm ci
npm test
npm run build
npm run dev
# 별도 셸에서
node tests/browser.mjs
```

QA 스크립트는 고정 분기 외에 E02와 E14에서 유효한 터미널 명령을 포함한 경로도 탐색합니다. 균등 무작위 선택 시뮬레이션은 터미널 명령을 자동 생성하지 않으므로 K5 발견률을 실제 난이도로 해석해서는 안 됩니다.

## v5 EVE 및 새 선택지

이전 근무와 조사 수첩 자리를 EVE 채팅 패널로 대체했습니다. EVE는 사건별 상황과 플레이어의 행동에 반응하며 농담, 빈정거림, 업무 의견을 전달합니다. E04의 배차 재협상 대화는 E04.d를 활성화하고, E05에서는 사진 원본 권한이 E05.d를 활성화합니다. 자세한 내용은 `V5_EVE_TERMINAL.md`에 있습니다.
