# v5: EVE, 터미널, 비공개 보관 기록

## 목적

기존의 종료 원인 분석은 보존하면서, 별도 `hint` 명령에 의존하지 않고 **행동 결과, EVE의 짧은 대화, 수신 메시지**로 다음 조사 단서를 전달합니다. 자유 입력 대화는 문장 패턴에 따른 설계된 반응이므로 범위를 벗어난 발화에는 자연스러운 응답을 제공합니다. 외부 LLM은 호출하지 않습니다.

## 변경 파일

- `src/eve.ts`: 사건별 첫 반응, 질문 반응, 선택 후의 말, 일부 대화에서 `eveCoord` 해금
- `src/EVEPanel.tsx`: 오른쪽 고정 EVE 채널, 짧은 주제 입력, 메시지 직접 입력
- `src/DispatchDesk.tsx`: 이전 근무 수첩 삭제, EVE 중복 메시지 제거, EVE 패널 배치
- `src/engine.ts`: `eve:<문장>` 명령 재생, 대화 이력과 `secrets` 보존, `term:cls` 화면 지우기
- `src/terminal.ts`: 터미널 편집, 사번/프로필 조회 차단, 숨겨진 기록 3종
- `src/content.json`: E04.d, E05.d, E06.d 추가
- `src/main.tsx`: EVE 메시지 핸들러와 기록 보관함의 비공개 원본 표시

## 업무 분기

- E04에서 EVE와 상점 조정을 논의하면 `eveCoord`를 얻고 E04.d 선택이 나타납니다. 지금 실적을 확보하지 못하지만 기사 휴식과 오후 환승장 경유 시간을 확보합니다.
- E06.d는 `rescheduled`에만 나타나며, 기사에게 추가 확인을 부탁해 봉인 번호 M2와 실적 1을 얻습니다.
- E05에서 터미널의 `auth request photo` 승인을 받으면 E05.d가 나타납니다. 고객 재배송을 보류하는 대신 원본 사진과 비정상적인 배경 반복이라는 단서를 남깁니다.
- 기존 사건, K4 진엔딩, K5 히든엔딩의 최소 도달 회차 및 판정 조건은 유지합니다.

## 숨겨진 보관 기록 (개발 참고)

- `R771` 접근 코드 `51-15`: 오배송 사진 원본을 다룬 뒤 터미널 수신으로 발견. 다른 날짜의 사진이 똑같다는 단서.
- `D204` 접근 코드 `08-12`: 전임자 블랙박스 또는 복원된 당일 비행 로그를 다룬 뒤 발견. 장애 재현에 대한 단서.
- `RELAY` 접근 코드 `07-58`: 회선 분리 실패에서 확보한 복구 로그와 지식 M4/M5가 필요. 근무 기록 초기화 규칙에 관한 단서.

`archive` 명령은 일반 `help` 목록에 표시하지 않습니다. `archive` 또는 `archive index`에서 문서 ID와 입력 형식을 볼 수 있습니다. 코드는 관련 사건의 수신 기록에서만 제시됩니다. 원본 조회 후 `state.secrets`에 영구 저장되어 기록 보관함에서 읽을 수 있습니다. 인사 명부와 직원 프로필은 정체 공개 이전과 이후 모두 조회 불가능합니다.

## QA

`node --experimental-strip-types docs/qa/check-design.mjs`로 엔진 전이를 검산합니다. EVE 대화와 사진 권한을 얻는 경로를 추가한 뒤 16사건/45전이/9결말을 확인했습니다.

브라우저 스크립트에는 `cls`, 사번 조회 거부, EVE 질문에서 E04.d 해금, 사진 권한으로 E05.d 해금, 비공개 기록 복구와 새로고침 보존 검사를 추가했습니다.

저장은 기존 v4 명령열을 그대로 재생할 수 있도록 version/key를 유지합니다. 현재 한계: EVE는 실시간 자유 생성 AI가 아니며, 뜻을 인식한 준비된 대화에 반응합니다. 소스에 정의된 커맨드 이외의 코드 실행은 지원하지 않습니다.
