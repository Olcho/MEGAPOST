# 선행 기록과 개인 기록

게임 내 기록은 `src/records.ts`에 제작자가 작성한 자료와 실제 플레이 명령 로그로 나뉜다. 미래의 실제 사용자 메시지는 아직 구현하지 않았다.

- 한윤서의 D-204 블랙박스: 신호가 끊기는 구간 및 원본 좌표 차이.
- 박지수의 현장 메시지 및 무인차 사진: 화물 C-918은 진료소가 아니라 환승장에 있다.
- 야간 실물 인계표: 서버 지시와 실물 배송을 구별해야 한다.
- MP-S17 배포 지침: 재현된 지시가 실제 배차망에 섞였다.
- 윤서의 회선 복구 기록: 실제 화물을 끊지 않고 회사 관제를 분리할 때 필요한 07:58 예약.
- MP-H07 정비 기록: 마지막에 발견하는 인간형 로봇의 물리적 기체와 초기화 방식.

영구 기억(M1~M6, W)은 회사가 따로 보관하는 안전 감사 구역과 EVE 봉인 기록으로 설명된다. 플레이어가 실제로 수행한 행동만 자신의 이전 근무로 표시한다. 제작자 기록을 실제 인간 플레이어의 메시지로 가장하지 않는다.
