# 관제 기록 보관함

| 출처 | 자료 | 실전에서 쓰이는 방식 |
|---|---|---|
| 제작 | 한윤서의 D-204 블랙박스 | 북쪽의 통신 단절. 오늘의 좌표를 따로 저장하며 강변으로 우회. |
| 제작 | 박지수의 현장 메시지 또는 예비차 봉인 사진 | 서버 도착 기록에 없는 실물 C-918을 확인. |
| 제작 | 야간 실물 인계표 | 기체 좌표와 실물 스캔을 붙여 테스트 배차를 분리. |
| 제작 | MP-S17 배포 지침 | 회사가 재현 세션의 지시를 실물 관제에 보내는 이유를 확인. |
| 제작 | 한윤서의 회선 복구 기록 | 다음 교대 전 시 안전망 예약 시각을 확인. |
| 개인 | 실제 행동과 그 이후 결과 | 근무 번호별로 보존. 다시 방문한 사건의 조사 수첩에서 지난 행동을 확인. |

제작 기록은 `src/records.ts`에서 해금 행동 ID와 연결한다. 기억은 엔진의 행동 효과로 따로 부여한다. 서술 자료가 중복되더라도 같은 영구 기억은 한 번만 등록된다. EVE의 봉인 수신증과 실제 행동 기록 역시 보관함에서 확인한다.

향후 비동기 공유 자료는 `community` 출처 타입의 별도 공급자로 제공할 수 있다. 이 판의 완주 경로와 세이브는 브라우저에서 자체 동작한다.
