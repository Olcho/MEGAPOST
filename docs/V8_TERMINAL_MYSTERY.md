# V8: 직관적인 조사 목표와 잔류 신호 연출

## 목적
사용자가 무엇을 조사하고 어떤 접근 권한을 확보할지 쉽게 알 수 있게 하되, 명령어와 대상 ID를 자동 완성하거나 정답으로 공개하지 않습니다. 기존 난이도와 분기 구조는 유지합니다.

## UI
- 배송관제와 터미널에서 동일한 현재 조사 목표를 표시합니다.
- 첫 회차에서 실제로 수행할 수 없는 과거 기록 복구를 권하지 않습니다.
- 권한이 없을 때는 어떤 종류의 권한이 필요한지, 발급 뒤에는 무엇을 조회해야 하는지 차례로 알려줍니다.
- `help`는 기본 문법만 표시하고, 사건 식별자를 미리 전부 나열하지 않습니다.
- 조사 대상의 이름, 코드, 기록 사용법은 기존 스토리에서 얻습니다.

## 미스터리 연출
- D-204 첫 사고의 일시적인 미확인 신호
- 동일 장애 기억을 획득한 이후에만 나타나는 보라색 잔류 궤적
- R-771 사진의 멈춘 네온 간판과 EVE의 가벼운 도시 괴담 대화
- 잔류 궤적은 실제 화물의 확인된 경로가 아니며 판정 로직에 영향을 주지 않습니다.
- 진엔딩/히든엔딩과 기존 반복 해금 조건은 변경하지 않았습니다.

## 검증
`npm test` 및 `npm run build` 후 실제 플레이어가 힌트만 보고 본인이 찾을 대상과 신청할 권한을 말할 수 있는지 확인합니다. 미스터리 연출을 버그나 확정된 화물 정보로 오인하는지도 관찰합니다.
