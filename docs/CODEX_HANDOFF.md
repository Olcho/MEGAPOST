# Codex 인수인계: MEGAPOST v5

## 작업 방식

기존 저장소의 변경 사항을 커밋하고 별도 브랜치에 이 ZIP의 파일을 복사하세요. `.git` 디렉터리나 원래 브랜치 기록을 교체하지 마세요.

## 주요 변경

- 이번 버전은 EVE 채팅 UI, 사번 조회 권한 제한, `cls` 화면 지우기, 3종 비공개 감사 기록 및 선택지 3개를 추가합니다.
- 기존의 `hint` 명령과 터미널 힌트 배너 및 두 문장짜리 설명 안내를 화면에서 제거했습니다.
- 기존의 `이전 근무와 조사 수첩` 영역은 EVE 채널로 대체했습니다.
- K4 진엔딩과 K5 히든엔딩은 그대로 유지합니다.
- `megapost.dispatch.v4` 저장 키와 `version: 4`를 **의도적으로 유지**하여 이전 v4의 진행을 잇습니다.

## 확인 항목

1. `npm ci`, `npm test`, `npm run build`.
2. 처음 출근한 플레이어의 사번 조회는 거부되어야 하며 E15의 정체가 노출되지 않아야 합니다.
3. E04에서 EVE에게 일정 조정을 요청하면 E04.d가 열려야 합니다. 해당 선택을 실행하면 E06.d가 열려야 합니다.
4. E05에서 터미널 사진 원본 권한을 받으면 E05.d가 열려야 합니다.
5. 사건 진행 중 보관 기록에 접근하면 원본이 저장되고, 재출근 이후에도 열람되어야 합니다.
6. `cls` 명령 후 터미널 표시가 비워져야 하며, 새로고침 이후에도 명령열 재생이 정상 작동해야 합니다.
7. 실제 브라우저에서 데스크톱과 모바일 사용성을 검증하세요.

상세 조건과 이스터에그 접근 단서는 `docs/V5_EVE_TERMINAL.md`에 기록했습니다.
