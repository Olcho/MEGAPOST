# v7 UI와 단서 전달 수정

## 요구 사항

1. 화면 길이에 따라 왼쪽 하단 메뉴가 위치를 바꾸지 않게 데스크톱 사이드바 높이를 고정함.
2. 업무 2개와 기록 2개를 위쪽에서 별도 범주로 유지하고, 설정은 하단에 분리함.
3. 배송관제의 조사 카드는 키워드와 조사 이유만 제시함. 클릭은 터미널로 이동하지만 입력은 자동완성하지 않음.
4. 터미널 도움말은 기본 동사와 자리표시자 구문만 소개함. 사건 도달 전 고유 식별자를 노출하지 않음.
5. 미발견 비공개 감사 색인은 나열하지 않음. 직원 프로필 접근 정책은 이전과 동일하게 거부함.
6. EVE 대사를 늘리되 회사의 반전이나 정답을 선공개하지 않음.
7. 배송 지도에서 불필요하게 친절한 직접 지시 문장을 제거함.

## 확인

- `npm test`: 도달 가능성, 조건, 반복 상태, 터미널 기록과 권한, EVE 대화 검사.
- `npm run build`: TypeScript 검사 및 Vite 배포 빌드. 프로젝트 구성에 맞게 설치 후 실행.
- 데스크톱에서는 관제, 터미널, 기록, 설정 메뉴의 사이드바 높이가 모두 같아야 함.
- 모바일에서 메뉴는 횡스크롤될 수 있지만 각 메뉴가 누락되면 안 됨.
- `help`와 `auth`를 아무 기록 없이 실행하면 등장하지 않은 고유 계정 및 후반 권한을 공개하지 않아야 함.
