# v8.1.2 — 감사 자료 도움말과 종료 대화

2026-11-25. v8.1.1 기반 마이너 핫픽스.

- 감사 자료를 발견하기 전에는 archive가 기본 도움말에 표시되지 않는다. R-771 원본/재배송 사진, D-204 비행기록, 회선 감사 잔재 중 하나가 확인되면 help 및 help archive를 통해 문법을 안내한다. 아직 발견하지 않은 문서 ID 및 접근 코드는 숨긴다.
- 색인/열람/도움말의 발견 조건을 통일하고, 발견 사실은 근무 전환 이후에도 보존한다. 기존 저장 명령열에서 재구성하므로 저장 키 및 버전은 그대로 유지한다.
- 모든 9개 결말에서 EVE의 질문을 종료 전용으로 분리. 회고, 실패 이유 또는 성과, 결과에 대한 반응. 자유 입력 역시 종료 전용 응답으로 처리하며, 새로운 업무 권한이나 미래 회차 공략을 노출하지 않는다.
- v8.1.1의 입력 포커스, 사진 권한 안내, 신규 선택지 강조, 종료 분석의 스포일러 제거를 포함한다.

검증: npm test 및 TypeScript 검사 통과(16개 사건, 45개 행동, 9개 결말). 브라우저 회귀 시나리오 추가, 실제 실행은 미검증. 정식 Vite 빌드 미검증.
