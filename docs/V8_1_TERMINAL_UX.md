# MEGAPOST v8.1 — 터미널 사용성 마이너 개선

v8의 이야기, 사건 16개, 행동 45개, 결말 9개와 저장 키 `megapost.dispatch.v4`는 유지합니다. 이번 변경은 터미널 조사 과정의 가독성과 입력 편의성을 개선하는 데 집중합니다.

## 조사 목표와 명령 입력의 분리

- 터미널 화면 위에 현재 사건, 지금 할 조사, 짧은 이유를 항상 보여 줍니다.
- 여러 단계가 있는 사건에서는 조회 → 권한 → 기록 확보 등의 진행 단계를 표시합니다. 완료한 단계는 체크로 바뀝니다.
- 화면에 완성된 명령어를 복사하거나 자동 입력하는 버튼을 두지 않습니다. 기본 명령 문법만 `help`에서 확인 가능합니다.
- 기존 세이브에서 권한을 먼저 얻은 경우에도 이미 끝낸 단계를 다시 강요하지 않습니다.

## 명령어 사용성

- 장비 식별자 `D204`, `D-204`, `D 204` 등을 같은 대상으로 받아들입니다. `R771`, `C918`, `MP S17`에도 적용합니다.
- 단, `archive open`의 문서 식별자와 접근 코드는 변환하지 않습니다. 별도 열쇠를 찾는 기존 이스터에그 규칙을 유지합니다.
- 대상이 없거나 잘못된 경우 기본 문법 또는 확인할 항목을 짧게 알려 줍니다. 정답이나 아직 발견하지 않은 계정 이름은 알려주지 않습니다.
- 입력창에서 ↑ 및 ↓ 키로 이번 근무의 이전 명령을 불러올 수 있습니다.

## 명령 실행과 실제 관제 연결

- `search D-204` 성공 시 이전 사고 조회를 완료한 것으로 표시합니다.
- 비행기록 권한 획득 후 로그를 열면, 완료 카드에 다음 행동을 보여 줍니다.
- 해당 이벤트에서 지도에 **확인된 강변 우회 후보**를 파란 점선으로 표시합니다. 아직 기체가 이동한 것처럼 보이지 않도록 구분합니다.
- 관제 화면에서도 **새 대응 발견** 카드와 실제 선택지 `E02.t`를 보여 줍니다.
- 이외 사진 원본, 시 안전망, 감사 권한도 성공 시 짧은 후속 행동 안내를 제공합니다.

## 검증

- TypeScript: `tsc --noEmit` 통과 (React 타입은 기존 전체 프로젝트에 동봉돼 있던 개발 패키지로 검사)
- 게임 분기: `node --experimental-strip-types docs/qa/check-design.mjs` 통과 (Node 22에서 실행)
- 대표 브라우저 시나리오는 `tests/browser.mjs`에 수정해 두었으나, Linux용 Rollup 및 esbuild 실행 파일이 없는 이 검사 환경에서는 브라우저 실행과 Vite 배포 빌드를 완료하지 못함

## 권장 실제 플레이 확인

두 번째 근무에서 D-204 통신 장애 화면을 열어 터미널로 이동합니다. 사고 기록을 조회하고, 비행기록 권한을 얻고, 로그를 복구해 봅니다. 각 단계마다 조사 카드가 한 단계씩 진행하는지, 관제 화면에 강변 우회 후보와 선택지가 표시되는지 확인합니다.
