# MEGAPOST v5 구현 및 QA 현황

## 구현

- 사이버펑크 배송관제 16사건, 45선택 전이, 9결말. K4 진엔딩과 K5 히든엔딩 유지.
- 근무 종료 후 실패 원인과 다음 교대에 도움이 되는 조사 단서 표시.
- 터미널 `cls`, 인사 프로필 접근 제한, 사진 원본 권한 및 숨겨진 감사 기록 조회.
- EVE 대화 전용 패널과 짧은 자유 입력/선택형 질문, 반응 및 E04.d 해금.
- E04.d, E05.d, E06.d 선택지 신설. 실제 근무 실적과 후속 조사에 영향.
- 비공개 자료는 기초 사건과 관제 수신 메시지의 표찰과 시각을 바탕으로 코드 추론 후 열람 가능.
- 기존 v4 명령열 저장과 재출근 보존 구조 유지.

## 검증 상태

- `tsc --noEmit`: 통과.
- `node --experimental-strip-types docs/qa/check-design.mjs`: 통과. 16사건, 45전이, 9결말.
- 핵심 회차 및 K4/K5 최단 4회차, EVE 대화 해금, 사번조회 접근 거부, `cls`, 숨겨진 기록 3종, 저장 명령열 재생 검증.
- `node --check tests/browser.mjs`: 테스트 스크립트 문법 통과.
- Linux 검증 환경에 Rollup 네이티브 모듈이 없고 npm 네트워크 설치가 되지 않아 Vite 빌드와 실제 브라우저 QA를 완료하지 못함. Windows 또는 종속성을 새로 설치할 수 있는 환경에서 반드시 `npm ci`, `npm run build`, `npm run dev`와 `node tests/browser.mjs`를 재실행해야 함.
